# 数字创新网络与企业资源配置

数字技术创新网络对企业资源配置效率影响的**实证研究复现代码**——经济学方法与 Stata 编码双能力的展示仓库。

> 本研究已在**广东经济学会中青年学者论坛（第 26 次会议）**报告。

## 研究问题

数字技术创新网络（DTE / DTU 指标）如何影响企业资源配置效率（以过度投资为核心结果变量）？

- **DTE**：企业数字化技术应用/采纳强度
- **DTU**：企业数字化技术使用广度
- **结果变量**：过度投资（OverInvestment），衡量资源配置偏离最优的程度

核心逻辑：接入数字技术创新网络 → 信息与资源配置优化 → 降低过度投资/提升配置效率。

## 方法路径

```
专利引用数据 → 构建企业引用网络 → 滚动窗口(t-5~t-1)测算 DTE/DTU 指标
        ↓
面板回归（企业-年份） + 固定效应 + 控制变量（规模/年龄/现金/研发/杠杆/成长/治理）
        ↓
异质性分析：产权性质 × 行业技术密集度 × 地理区位
```

四个 do 文件对应完整流程：

| 文件 | 步骤 |
|---|---|
| `do/01_citation_matrix.do` | 专利引用矩阵构建（清洗自引、长格式网络数据） |
| `do/02_citation_matrix_v2.do` | 引用矩阵 v2（迭代优化） |
| `do/03_dte_dtu_rolling_window.do` | DTE/DTU 滚动窗口（t-5 至 t-1）测算 |
| `do/04_heterogeneity_analysis.do` | 主回归 + 异质性分析（产权/行业/区位） |

## 数据来源

以下数据为**受许可的企业级数据，未包含在本仓库**（复现前需自行获取并放入 `data/` 目录）：

- 上市公司专利引用数据（1985~2024，上市公司与专利匹配结果）
- 过度投资数据（OverInvestment_Data.dta）
- 政府补助数据（2007~2024）
- 员工结构数据（2011~2023）

`do/` 文件中的路径已脱敏为相对路径（`data/...`）。运行前将对应 `.dta` 放入 `data/` 并调整路径即可。

## 复现

```bash
# 环境：Stata 15+，需安装 reghdfe 等社区包
# 1. 放置数据到 data/（受许可数据，需自行获取）
# 2. 依次运行：
stata-mp -b do/01_citation_matrix.do
stata-mp -b do/02_citation_matrix_v2.do
stata-mp -b do/03_dte_dtu_rolling_window.do
stata-mp -b do/04_heterogeneity_analysis.do
```
